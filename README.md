# 🔐 Password Cracking & Hash Analysis

Hands-on cybersecurity project exploring password security, conducted during my Cybersecurity Internship at **Networkwalks Technologies**.

## 📋 Overview

This project investigates how weak passwords and poorly secured hashes can be compromised by attackers. Using both industry-standard and specialized tools, I explored password cracking techniques, hash generation, and the real-world impact of hashing practices on security.

## 🛠️ Tools Used

### John the Ripper (JTR)
A widely-used, open-source password-cracking tool used by security professionals to audit password strength. JTR tests hashed passwords through:
- **Dictionary attacks** — testing common passwords/wordlists
- **Brute-force attacks** — systematically trying character combinations
- **Hybrid attacks** — combining dictionary words with variations (numbers, symbols)

### NetworkWalks Hash Calculator & Password Cracker
Used to generate password hashes using various algorithms and test how easily they could be reversed or cracked.

## 🎯 What This Project Covers

- Generating and analyzing password hashes across different algorithms
- Performing dictionary, brute-force, and hybrid attacks using JTR
- Comparing crack times across varying password complexities and hash types
- Understanding the impact of salting on hash security
- Identifying weak password patterns commonly exploited by attackers

## 💡 Key Takeaway

Weak or unsalted hashes can be cracked in seconds, while strong hashing algorithms combined with salting and complex passphrases make cracking exponentially harder — even for powerful tools like JTR. This project reinforced why proper password policies and hashing practices are essential to real-world security architecture.
